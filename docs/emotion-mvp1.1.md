## 已有能力与本次增量

此前情感 MVP 已有独立情绪状态、事件触发、状态边界、30 分钟半衰期、持久化、直接夸奖识别、宿主完成/错误事件、勿扰、主动互动冷却、事件去重、开关与重置。1.1 沿用这些能力，增加诊断、复现用例、表达规则和自动正文避重，并修复实际安装中发现的原生诊断协议兼容问题。

### 连续情绪与真实事件

每只宠物独立保留效价 `[-1, 1]` 和活跃度 `[0, 1]`，基线为 `(0, 0.35)`，偏差随时间回归。情绪数据仍为兼容旧版 v1 的 `emotion.json`。不因用户离开、沉默或不回复而扣分，不依据模型猜测生成用户状态。

直接夸奖采用保守规则；引用、第三人称转述和普通问候不计作直接夸奖。宿主回合完成只是可观测的执行终态，不能当作用户确认成果或质量正确。

旧版每秒一次连续完成事件在第 4 次使效价达到 1、第 5 次使活跃度达到 1；该问题先由冻结旧源码和宿主测试复现。1.1 将完成事件增量从 `(+0.30, +0.16)` 调整为 `(+0.08, +0.04)`，同一宠物、同一宿主会话 10 分钟固定窗最多接受 3 次，后续标为 `session-completion-limit`。测试中的 8 次连续完成最高约为 `v=0.239908, a=0.469954`。来源摘要上限 32、事件 ID 上限 128，属于有界短期保护；重启继续生效。

### 表达与已有动画

固定人设说明身份和习惯，心情影响用词与节奏，当前明确请求和观测事实决定回答内容。技术回答不再受日常碎碎念“20 字以内”规则限制；准确性、完整解释和必要代码优先。当前错误或排错情境优先于高心情，使用支持性策略和既有待机动画，避免庆祝。普通新问候不自动背负历史错误情境。

没有代码或具体报错时，不得声称已经看过、理解或修复；宿主 completed 不得写成用户认可成功。现有形象与动画素材保留，缺素材时降级为文字。安静陪伴是合法结果，不强制每次情绪变化都说话。程序只能验证表达路由和注入规则，真实模型是否自然遵循仍待验收。

### 主动互动保护

沿用勿扰、真实工作档位、5 分钟冷却、事件去重、生成中设置修订保护及提交前复查。生成期间开启勿扰后，旧自动结果不再提交。显式人工聊天和手动碎碎念保留原入口。

自动碎碎念另有独立的正文避重：NFKC、大小写、Unicode 标点和空白归一后的精确摘要匹配；每宠物最多 16 个 SHA-256 摘要、30 分钟有效，总共最多 128 只宠物。只保存摘要和时间到 `whisper-content.json`，不保存正文，不承诺语义近似去重。检查在原提交保护之后，成功发布才记入；重复或归一后为空则安静丢弃，不额外重试，保留已消耗冷却。人工聊天及手动碎碎念既不检查也不写入该缓存。

没有增加长期记忆、关系分、语音、工具执行或新模型。多进程共享数据根的文件锁不在本阶段范围内。

## 设置与本地诊断

入口为 **DSH 主窗口 → 设置 → 桌宠配置 → 选中宠物 → 展开本地情绪诊断**，不在桌宠右键菜单。设置中保留“连续情绪”“勿扰”“重置全部宠物情绪”。重置不清聊天，不绕过冷却，也不清自动正文避重窗口。

诊断复用情绪查询，仅展开、刷新和切换宠物时读取，不轮询、不生成模型文本、不写配置。显示构建、已生效开关、状态变化、事件接受/忽略原因、表达策略、动画选择和主动互动拦截原因。每宠物最多 80 条、最多 128 只宠物，进程内保存，重启清空。记录使用元数据白名单，不保存聊天原文、完整提示词、模型回复、会话身份、错误正文或密钥。

诊断详情要求真实 loopback socket、严格本机 Host 和诊断请求头。HTTP 页面还需符合本机同源来源与 Fetch Metadata 约束；DSH 原生 `dsh-app://app/` 转发分支还需宿主已有 `connection.requestRejection(req)` 会话验证通过，验证方法缺失、抛错或拒绝均拒绝访问。普通状态查询保持兼容；没有新增外部端点或凭证。详情读取使用 `no-store`。具体契约见 [API](../API.md) 和 [OpenAPI](../openapi.yaml)。

首次安装测试发现原生转发会移除 Origin/Fetch Metadata，且可能缺少 Referer；旧构建因此 403。最终 `.3` 构建复用上述现有宿主会话验证修复，真实设置页已确认可用，同时未认证的原生形态本机请求实际返回 403。早期 `0.3.7-emotion.1.1` 和 `.1.1.1` 不是推荐安装目标。

公开默认配置 `emotionEnabled=true`、`doNotDisturb=false`。安装验收机器为避免自动模型调用临时保持勿扰开启，其余配置和聊天记忆保留；这是该机器的用户配置，不是仓库默认值。需要继续保持零模型调用时，在任何重启前确认用户层勿扰为 true，且不发起人工聊天或手动碎碎念。关闭勿扰后自动互动可能调用模型。

## 从源码构建与离线复现

Node 下限见包内 `engines`（`>=22.12.0`）；本次使用 Node 24。先进入仓库下的插件子目录 `dsh-pet/`，按项目声明安装开发依赖；联网安装依赖不等于真实模型测试。

```powershell
cd dsh-pet
npm install
npm run test:emotion
npm run prepack
npm pack --ignore-scripts
```

`test:emotion` 先构建，再运行专项源码与宿主模型桩测试。`prepack` 是完整发布检查链；这里只在它成功之后使用 `npm pack --ignore-scripts` 避免重复构建。仅运行裸 `tsdown` 不会生成全部桌面共享核心与类型。`lib/` 是生成物，不入源码提交。

其它离线复现命令：

```powershell
# 完整源码套件；建议串行运行，避免 Windows 临时目录操作冲突
node --experimental-strip-types --import ./scripts/test-register.mjs --test --test-concurrency=1 src/**/*.test.ts

# 已安装系统 Chrome 时的设置页 fixture；否则沿用项目 Playwright Chromium
$env:DSH_PET_TEST_BROWSER_CHANNEL = 'chrome'
node --test scripts/tests/settings.test.mjs

# 最终兼容修复的针对性检查
node --experimental-strip-types --import ./scripts/test-register.mjs --test src/host/emotion-diagnostics.test.ts
node --test scripts/tests/emotion-host.test.mjs
```

测试不需要 API Key。浏览器 fixture 需要对应浏览器及本机 loopback 访问。Windows 临时目录受限时，可为该测试进程设置独立可写 TEMP/TMP；不要把个人 DSH 数据目录用作测试数据根。

## 安装与回滚

以下是通用 Windows 步骤，不表示读者机器已安装。先在 DSH 正常退出后，将当前 desktop profile、桌宠用户数据目录和上一版已验证本地包备份到私有位置。用户数据通常在 `$DSH_HOME/dsh-pet`，默认 DSH_HOME 通常为 `~/.dsh`；以实际启动配置为准。不要将备份、凭证或真实聊天上传仓库。

为避免启动即自动生成，可在退出状态下只修改用户配置现有 `doNotDisturb` 开关为 true，保留原文件及其它字段。使用实际 DSH 官方 CLI 路径；若其已在 PATH，可以执行：

```powershell
# 将路径替换为刚构建并核对的实际绝对路径，file: 使用正斜杠
dsh plugin --profile desktop add 'file:D:/build/dsh-pet-0.3.7-emotion.1.1.2.tgz'
```

不要直接编辑安装目录中的 node_modules。确认 CLI 成功后重开 DSH，在诊断入口核对 `emotion-mvp1.1-20261023.3 / 0.3.7-emotion.1.1.2`；标识不符时先检查 profile、旧进程与安装结果。此操作保留用户聊天和配置，升级后应另行核对。

本次实际安装的本地包为 62,563,499 字节、327 文件，SHA-256 为 `90bae531c0242d8820c9cc4c0544a85021abb5a2267e0a86157669dc64925a0e`。自行重新打包的 tgz 可能因打包元数据不同而拥有不同哈希；该历史哈希只用于识别那一份本地交付包，不是所有重新构建的预期值。仓库源码提交不意味着附带该二进制包。

回滚时正常退出 DSH，用同一官方 CLI 安装事先保留的**上一版已验证本地包**，再重开并检查。示例：

```powershell
dsh plugin --profile desktop add 'file:D:/backup/previous-verified-dsh-pet.tgz'
```

不要用旧用户数据覆盖升级后新增的聊天，不要删除 memory.json、配置或凭证。若目标是此前情感 MVP，注册表原版 `0.3.7` 不能替代那份本地 MVP 包。实际回滚尚未执行。
